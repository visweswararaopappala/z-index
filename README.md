*** CSS Z-Index

A simple HTML and CSS project to understand how the **`z-index` property** works.

*** About

This project demonstrates how elements can be placed **above or below other elements** using CSS `z-index` and positioning.

It includes examples with:

*  Overlapping boxes
*  Overlapping images
*  Different `z-index` values
*  CSS positioning

** Technologies Used

* HTML5
* CSS3

** How to Run

1. Clone the repository:

```bash
git clone https://github.com/visweswararaopappala/z-index.git
```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Open `index1.html` to see the second example.

** Purpose

This project was created to practice **CSS positioning and the `z-index` property** and to understand how overlapping elements are arranged on a webpage.
